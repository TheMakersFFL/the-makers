# The Makers — Wednesday Weekly Update Checklist

Use this checklist for every in-season update. The site gets **one combined Wednesday update after waivers clear**.

- [ ] Wait until Wednesday waivers have processed.
- [ ] Set Upcoming Week to the week about to be played.
- [ ] Run the current Makers collector in **WEDNESDAY** mode.
- [ ] 10/10 standings captured.
- [ ] 5/5 completed matchups captured.
- [ ] 10/10 completed lineups captured.
- [ ] 10/10 scoreboard reconciliation passes.
- [ ] 10/10 current post-waiver rosters captured.
- [ ] 5/5 upcoming Yahoo matchup projections captured.
- [ ] 100/100 available-player pool captured.
- [ ] Transactions deduped to the real structured moves.
- [ ] Preserve raw collector JSON until the update is validated.
