THE MAKERS — 2026 WEDNESDAY UPDATE GUIDE

LIVE SITE
https://themakersffl.github.io/the-makers/

ARCHITECTURE
The 2026 live site now uses one combined Wednesday publishing workflow layered on top of the locked historical archive.

Historical baseline:
  - data.js = 2022–2025 archive + locked 2026 draft/schedule/keeper baseline.
  - Do not rewrite completed historical seasons during ordinary weekly maintenance.

Current live-season layer:
  - Dynamic pages use the local Makers weekly runtime and makers-weekly-loader.js.
  - Wednesday is the only active in-season collection and publishing workflow.
  - Retired split-cadence renderer files are not part of the production runtime.

WEDNESDAY COMBINED UPDATE — AFTER WAIVERS
1. Wait until Wednesday waivers have processed.
2. Set Upcoming Week to the week about to be played.
3. Run the current Makers collector once in WEDNESDAY mode.
4. Validate before publishing:
   - 10/10 standings
   - 5/5 completed matchups
   - 10/10 completed lineups
   - 10/10 score reconciliation
   - 10/10 current post-waiver rosters
   - 5/5 upcoming Yahoo projections
   - 100/100 available-player pool
   - structured transactions deduped and reconciled
5. Freeze the completed-week receipts:
   - final scores and standings / PF / PA / streak
   - all-play results
   - lineup efficiency and optimal-lineup receipts
   - weekly superlatives and Game of the Week
   - Makers-vs-Yahoo prediction grading
6. Update the post-waiver state:
   - waiver adds/drops and FAAB / priority
   - current rosters
   - remaining waiver/free-agent opportunities
   - meaningful injuries/statuses
   - team needs and transaction ROI
7. Rebuild all current model/editorial boards:
   - Homepage weekly feature
   - Weekly Write-Ups archive
   - 2026 War Room
   - Power Rankings / Power Index
   - Playoff / bye / title / toilet odds
   - Race Dashboard / Projected Field
   - Franchise Stock Market
   - What Everybody Needs
   - Waiver Wire and Moves / transaction tape
   - Predictions ledger and Analytics
   - Schedule roads with completed-week W/L receipts
   - Franchise dashboards
   - Career standings / League Ledger / Record Book audit
   - H2H matrix and complete game log
   - Season History active chapter
8. Publish the full upcoming-week preview:
   - all five matchup previews
   - locked Makers winner pick for every game
   - locked Makers projected score for every game
   - frozen Yahoo projection snapshot for comparison
   - Game of the Week
   - matchup H2H/history notes where useful
   - lineup, roster, injury and playoff implications
9. Freeze the Wednesday prediction receipt before games begin.
10. Commit to main and confirm GitHub Pages deploys successfully.
11. Final QA:
   - JS syntax checks pass
   - all live routes render without exceptions
   - internal links/assets resolve
   - ten unique active teams/managers are represented
   - completed-week set covers all ten teams once
   - upcoming-week set covers all ten teams once

PREDICTION RULE
Wednesday = official weekly prediction lock for both Makers and Yahoo comparison snapshots.
The locked Wednesday receipt must not be rewritten after games begin.
The following Wednesday grades those predictions before the next set is locked.

HISTORY RULES

DEPLOYMENT RULE
Normal weekly updates are committed directly to the main branch of TheMakersFFL/the-makers. GitHub Pages deploys automatically from main. Manual ZIP replacement is not part of the normal workflow.
